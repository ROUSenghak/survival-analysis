\begin{abstract}
Layer 1, \texttt{boamp\_only}, is the primary BOAMP-native specification. It
uses only identifiers present in BOAMP: valid SIRET, then SIREN, then normalized
buyer name. The 2026-07-27 end-to-end run contains 84{,}623 cleaned notices and
3{,}380 eligible digital/ICT source contracts. The Layer-1 blocker produces
10{,}862 candidate pairs over 2{,}005 sources. At the refreshed balanced
threshold \(0.343167\), the handoff contains 1{,}003 proxy-renewal events
(29.7\%) and 2{,}377 censored sources (70.3\%). Median survival is not reached;
restricted mean survival time at 60 months is 43.51 months.
\end{abstract}

\section{Scope and Implementation}

The source population is Pays de la Loire BOAMP notices from 2015-01 through
2026-07, filtered to digital/ICT contracts by CPV divisions 32, 35, 48, 72 or
the configured keyword scope. The current cleaned corpus and Layer-1 artifacts
are produced by:
\begin{itemize}
    \item \texttt{notebooks/01\_data\_engineering\_pipeline.ipynb};
    \item \texttt{notebooks/02\_eda.ipynb};
    \item \texttt{notebooks/03\_analysis.ipynb};
    \item \texttt{data/processed/boamp\_only/};
    \item \texttt{reports/tables/}.
\end{itemize}

For source notice \(i\) and later candidate \(j\), the score is
\[
S_{ij}=0.35s_{\mathrm{text}}+0.30s_{\mathrm{cpv}}+0.25s_{\mathrm{time}}+0.10s_{\mathrm{buyer}}.
\]
Only the rank-1 candidate for each source may be accepted. The refreshed
Layer-1 rank-1 percentile thresholds are:
\[
\tau_{\mathrm{broad}}=0.278387,\quad
\tau_{\mathrm{balanced}}=0.343167,\quad
\tau_{\mathrm{strict}}=0.442070.
\]

\section{Interpretation}

Layer 1 is internally coherent and remains the primary specification because it
does not depend on external buyer enrichment. Its main limitation is blocking:
1{,}375 eligible sources never receive a candidate and are structurally
censored. The 327 POTENTIAL-tier links are retained in the event set but must be
treated as lower-evidence links in sensitivity analysis.

The duration covariate is not causal. Duration is used to construct estimated
end dates, temporal blocking, temporal scoring, and the survival covariate
itself. The duration-leakage counterfactuals in \texttt{notebooks/03\_analysis.ipynb}
therefore remain part of the evidence standard for any survival interpretation.
