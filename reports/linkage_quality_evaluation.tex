\begin{abstract}
This report audits the current BOAMP proxy-renewal linkage handoff. The
reference event is still a constructed linkage event, not verified legal
renewal truth. The 2026-07-27 run contains 3{,}380 eligible sources. Layer 1
produces 10{,}862 candidate pairs and 1{,}003 balanced links; Layer 2 produces
13{,}524 candidate pairs and 1{,}188 balanced links. The shared balanced
threshold is \(0.343167\). Blocking remains the largest quality constraint,
and the duration variable remains a high-risk design input because it affects
candidate generation, temporal scoring, and survival modeling.
\end{abstract}

\section{Reference Rule}

For each eligible source contract, the pipeline searches later notices from the
same buyer identity within the configured temporal window around the estimated
contract end date. Candidate scores combine text, CPV, temporal proximity, and
buyer-identity reliability:
\[
S_{ij}=0.35s_{\mathrm{text}}+0.30s_{\mathrm{cpv}}+0.25s_{\mathrm{time}}+0.10s_{\mathrm{buyer}}.
\]
Only the rank-1 candidate can be accepted. The current Layer-1 percentile
thresholds are \(0.278387\), \(0.343167\), and \(0.442070\) for broad,
balanced, and strict variants.

as sensitivity evidence rather than as verified renewals.

\section{Main Findings}

\begin{enumerate}
    \item Layer 2 materially increases candidate coverage and accepted proxy
    events, but it also shifts the evidence mix toward lower text similarity and
    lower margins.
    \item The balanced event remains a proxy. No manual-validation file in the
    current repository contains completed labels sufficient for a verified
    precision claim.
    \item Blocking, not scoring alone, is the binding ceiling: 1{,}375 Layer-1
    sources and 1{,}215 Layer-2 sources have no candidate.
    \item Duration leakage remains central. Duration determines estimated end
    dates, temporal blocking, temporal scoring, and then appears as a survival
    covariate. Any causal reading of the duration hazard ratio is unsupported.
\end{enumerate}
